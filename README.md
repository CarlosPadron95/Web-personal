## Descripción (Español)

Sitio web personal y portafolio profesional interactivo de Carlos Padrón, diseñado con un estilo editorial brutalista y con soporte bilingüe nativo.

### 📋 Descripción

Esta aplicación permite:
- **Presentar** el perfil profesional, servicios y trayectoria de Carlos Padrón como desarrollador Full-Stack.
- **Mostrar** proyectos destacados con enlaces directos a sus respectivos repositorios y demostraciones en vivo.
- **Listar** habilidades técnicas y certificaciones ordenadas estratégicamente para reclutadores.
- **Contactar** mediante un formulario interactivo con validación de datos y envío real de correos a través de la API de Web3Forms.
- **Alternar** el idioma de todo el sitio entre español e inglés de manera dinámica, persistiendo la selección del usuario.

### ✨ Características
1. **Diseño Editorial Brutalista Premium**: Interfaz moderna y sofisticada con una paleta de colores beige y verde bosque, sombras planas compensadas, tipografía cuidada (Outfit y Plus Jakarta Sans) y un retrato lineal personalizado.
2. **Sistema de Idiomas Dinámico**: Traducción completa sin recargas de página mediante JavaScript nativo, gestionando las claves en un diccionario centralizado y persistiendo la preferencia del usuario en `localStorage`.
3. **Optimización y Accesibilidad**: Estructura semántica en HTML5, etiquetas meta SEO (Open Graph), e iconos adaptables renderizados con Lucide Icons y SVGs incrustados.

### 🎯 Casos de Uso
- Carta de presentación digital interactiva y portafolio profesional para reclutadores y clientes.
- Demostración de diseño responsivo moderno y maquetación web fluida usando CSS Grid y Flexbox.
- Ejemplo de lógica frontend interactiva en JavaScript vainilla (sin frameworks complejos).

<a name="english"></a>
## Description (English)

Personal website and interactive professional portfolio of Carlos Padrón, designed with a brutalist editorial style and featuring native bilingual support.

### 📋 Description

This application allows users to:
- **Present** Carlos Padrón's professional profile, services, and career path as a Full-Stack developer.
- **Showcase** highlighted projects with direct links to their repositories and live demos.
- **List** technical skills and certifications organized strategically for recruiters.
- **Contact** through an interactive form with data validation and real email delivery via Web3Forms API.
- **Toggle** the site's language dynamically between Spanish and English, persisting the user's preference.

### ✨ Features
1. **Premium Brutalist Editorial Design**: Modern and sophisticated interface featuring a beige and forest green color palette, flat offset shadows, carefully chosen typography (Outfit & Plus Jakarta Sans), and a custom line-art portrait.
2. **Dynamic Language System**: Full translation without page reloads using native JavaScript, managing keys in a centralized dictionary and persisting the user's choice in `localStorage`.
3. **Optimization & Accessibility**: Semantic HTML5 structure, SEO meta tags (Open Graph), and responsive icons rendered via Lucide Icons and embedded SVGs.

### 🎯 Use Cases
- Interactive digital cover letter and professional portfolio for recruiters and clients.
- Demonstration of modern responsive design and fluid layout using CSS Grid and Flexbox.
- Example of interactive frontend logic using vanilla JavaScript (without complex frameworks).
